# 아스메지카 그레이박스 상세 제작 기획서

2026-11-24 · 기준 문서 「아스메지카 게임 시스템 기획서 v6」 · Unity 6000.3.28f1

## 플레이어가 경험할 한 사이클

탐험 방 입구에서 닫힌 문과 충격판을 본다. 방패를 아는 상태로 발판을 올라 `발사`를 얻고 돌아온다. 방패와 발사를 묶어 쏘면 방패가 판에 닿아 문이 열린다. 문을 지나 배운 단어를 덱에 넣고, 슬러그 1~3마리의 다음 행동을 읽어 같은 투척 방패로 투사체를 막는다. 전투 결과에서 다시 시도할 수 있다. 별도 고정 손패 모드에서는 문을 여는 과정 없이 두 계획의 결과를 반복 비교한다.

## 기능 1 · 두 모드가 공유하는 주문 문법

화염·방패는 메인, 발사·강하게는 보조이며 각 단어의 시험 비용은 1이다. 그룹의 마지막 메인이 본체다. 앞선 화염은 방패에 불 속성을 입힌다. 방패 뒤 화염, 중복 단어, 빈 그룹, 보조만 있는 그룹, 알 수 없는 단어는 거절한다. 보조는 메인 전후 어디든 올 수 있다. 해석기는 이름·본체·발사·불 속성·강화·비용을 돌려준다. 실패하면 한국어 사유를 표시하고 호출자의 입력과 자원을 보존한다.

검수자는 `[화염, 발사]`와 `[발사, 화염]`, `[화염, 발사, 방패]`와 `[발사, 화염, 방패]`가 각각 같은 결과인지 확인한다. 세 장을 두 그룹으로 나누었을 때 결과가 서로 독립적이어야 한다. 강화의 임시 증가량은 1이다.

## 기능 2 · 고정 손패와 1 대 1~3 전투

- 전투 편집기에 플레이어 HP·마나, 대상별 HP, 적별 예지 다섯 칸, 편집 중인 그룹, 예약 카드와 계획 칸을 표시한다. 카드 선택 순서대로 조합하며 배치 전에 이름·비용 또는 오류를 보여 준다. 공격 주문은 대상 한 마리를 지정한다. 주문 이동·해제와 대상 재지정은 확정 전에 가능하다.
- 카드마다 고유 ID를 부여한다. 검증이 끝난 계획만 총비용을 한 번 지불한다. 실패나 편집은 무료다. 실행 중 재확정은 무시한다. 빈 칸과 빈 계획도 유효하다.
- 각 칸 시작 시 생존 목록을 고정한다. 제자리 방패는 해당 칸의 수신 공격에 방어력 2를 공유한다. 투척 방패는 지정 적의 차단 가능한 투사체에 방어력 2를 제공한다. 초과분은 피해다. 동시에 들어오는 공격은 적 ID순으로 방어량을 배분한다. 같은 칸에 양측이 행동하면 피해를 모아 동시에 적용한다. 동시 전멸은 패배로 판정한다. 앞선 칸에서 죽은 적의 후속 행동은 취소로 남기고 죽은 대상을 향한 주문은 빗나간다.
- 첫 적의 패턴은 대기→접근→준비→공격(3)→후퇴다. 추가 적은 공격 시점을 어긋나게 배치하고 근접/투사체를 예지에서 구분한다. 시험용 기본 화염은 근거리, 화염구는 원거리까지 명중한다. 피해는 화염구 2, 불붙은 투척 방패 4다. 적 수 선택은 1·2·3을 모두 제공한다.
- 고정 손패는 화염·발사·방패, 시작 마나는 3, 양측 체력은 6이다. A는 2칸 화염구와 4칸 방패로 내 HP 5/적 HP 4/마나 0, B는 2칸 불붙은 투척 방패로 3/2/0이다. 적 HP 4로 B를 실행하면 내 HP 6을 보존하고 4칸 공격은 취소된다. 2~3마리에서는 원래 대상의 사망이 다른 적의 행동을 지우지 않는지 확인한다.

## 기능 3 · 편성 덱과 다음 턴

일반 인카운터에서 습득한 단어만 덱에 추가한다. 시험값은 단어당 최대 2장, 덱 3~8장, 턴 손패 최대 4장, 매 턴 마나 3으로 한다. 덱 크기가 손패보다 작으면 보유 장수만 뽑는다. 주문 확정 뒤 턴 종료 시 손패 전부를 버리고 뽑을 더미가 비면 버린 더미만 섞는다. 같은 이름의 서로 다른 카드는 서로 다른 주문에 예약할 수 있다. 메인이 없는 손패는 빈 계획으로 진행 가능하다. 고정 비교 모드는 항상 같은 손패를 공급한다.

검수자는 두 번 이상 덱을 순환시키며 ID 보존·카드 복제·예약 해제를 확인한다. 같은 시드에서 순서 재현, 편성 밖 단어 미출현, 부족한 마나, 메인 없는 손패를 포함한다.

## 기능 4 · 탐험 방과 전투 연결

입구와 문, 충격판, 발사 단어를 얻을 발판을 한 화면 또는 짧은 왕복 동선에 배치한다. 플레이어·벽·문·발판은 단색 도형으로 구분한다. 입구에서 필요한 조작을 표시한다. 단어를 얻기 전에는 방패만 시전할 수 있다. 화염·강하게도 일반 덱에서 시험할 수 있도록 추가 습득 경로를 둔다. 발사 획득 후 방향을 맞춰 시전한다. 충격판은 투척 방패가 실제로 닿을 때만 반응하고, 판 색 또는 점멸과 짧은 소리로 문 개방을 알린다. 빗나감·제자리 방패·중복 충돌·재입장도 확인한다. 통과한 문에서 인원과 덱을 선택하고 전투 종료 후 재시작한다.

## 제작 및 승인 순서

각 기능을 순서대로 Claude Code의 Haiku 5.5 Max로 처음 구현한다. 기능별로 실행 가능한 사례를 돌리고 `agy` Gemini 4 Neon High가 1차, Claude Code Opus Extra High가 2차로 검증한다. 이 세션이 각 보고서의 지적을 기획 및 실행 결과와 대조하여 승인·수정·재검증을 결정한다. 변경된 동작은 해당 검증을 다시 받는다. 보고서는 `Docs/Asmegica/Reviews`에 기능·차수별로 보관하고, 모델, 검토 범위, 실제 실행 증거, 발견 사항, 조치와 다음 단계 여부를 기록한다.

마지막 인수는 전용 씬 진입, 탐험→덱→전투→결과·재시작, 고정 A/B 재현, 1·2·3마리 전투를 대상으로 한다. 사람 대상 플레이테스트에서는 메인 없는 턴, 선택지가 하나였던 턴, 예지와 예상이 처음 갈린 칸, 도움 없이 투척 방패를 재사용했는지를 별도 관찰한다.
