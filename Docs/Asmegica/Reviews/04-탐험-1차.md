# 탐험 방과 전투 연결 · Gemini 1차 검증

2026-11-24 · Gemini 4 Neon High · 1회차 REVISE

Unity의 탐험 규칙 검사는 통과했다. 실제 Play Mode 검사기는 첫 실행에서 Unity 검색 인덱스 시작 예외를 포착해 시나리오 전에 중단됐다. 작업자가 해당 에디터 내부 예외만 검사 대상에서 분리한 뒤 일반 경로의 플레이 검사가 통과했다.

Gemini는 기본 동선 밖의 세 경우를 지적했다. 오른쪽에서 높이 4의 발판을 올라 왼쪽으로 돌아가기 어려운 점, 문 통과 후 재진입 시 같은 전환을 다시 일으킬 수 있는 점, 탐험으로 돌아온 뒤 덱 출처 플래그가 남을 수 있는 점이다. 이 세션은 우측 왕복 동선과 페이지 전환을 보완하고 재현 회귀 검사를 추가하도록 지시했다.

2회차 정적 재검토는 PASS였다. 추가 디딤턱의 높이와 점프 높이, 문 접근 위치, 덱 출처 초기화를 검토했다. 그러나 Unity에서 새 왕복 검사를 실행하자 600프레임 안에 왼쪽으로 넘어가지 못했다. 이 세션은 승인을 보류하고 실제 충돌 처리 재작업을 지시했다.

3회차 PASS. 착지 후 부동소수점 오차로 발이 디딤턱 안에 약간 남아 다음 수평 이동에서 밀려나는 문제였다. 작업자가 캐릭터의 지형 접촉 판정에 0.0001 유닛 허용차를 적용했다. 종전과 동일한 시간·거리·높이 조건에서 우측 왕복 검사와 전체 Play Mode 검사가 통과했다. Gemini가 변경을 재검토했고 이 세션은 2차 검증으로 진행했다.
