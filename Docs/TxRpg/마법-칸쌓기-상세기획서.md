# 마법 조합 · 칸 쌓기 상세 기획서

브랜치: `claude/magic-slot-stack`
대상: 전투 씬(`BattleTest`)의 5칸 타임라인, 탐험 퍼즐 방의 주문 입력

## 1. 왜 바꾸나

기존 방식은 손패에서 카드를 골라 **초안 그룹**을 만든 뒤 칸에 배치했다. 문제는 세 가지였다.

- 단계가 두 번이다. 카드 → 초안 → 칸.
- 숨은 규칙이 있다. "마지막 메인이 본체", "화염은 방패보다 앞에" 같은 규칙이 화면에 보이지 않는다.
- 모양이 들쭉날쭉하다. 단어 N개 주문은 발동 칸에서 거꾸로 N칸을 차지해서, 빈 칸에 "영창 중" 글자만 남는다.

새 방식은 **칸이 곧 그룹**이고 **타임라인이 곧 문장**이다.

## 2. 단어는 두 종류

| 구분 | 단어 | 타임라인에서 |
|---|---|---|
| 메인 | 화염, 방패 | **칸 하나를 차지한다** |
| 서브 | 발사, 강하게 | **칸을 차지하지 않고 메인 위에 쌓인다** |

카드 한 장의 마나 비용은 1이다(기존과 같음).

## 3. 규칙

1. **한 칸 = 메인 1장 + 서브 0~2장.** 같은 서브는 한 칸에 한 장만 붙는다.
2. **서브는 자기가 놓인 칸의 메인만 꾸민다.**
3. **이웃한 칸의 메인은 문장으로 이어진다.** v1에서 이어지는 짝은 하나뿐이다.
   - `[화염]` 바로 다음 칸에 `[방패]`가 오면 이어진다.
   - 앞 칸의 화염에 **발사**가 붙어 있으면 이어지지 않는다. 화염이 이미 날아갔기 때문이다.
   - 그 밖의 짝(방패→화염, 화염→화염 등)은 이어지지 않고 각자 발동한다.
4. **이어진 문장은 마지막 칸에서 한 번 발동하고, 앞 칸은 영창이 된다.** 영창 칸에서 피해를 입으면 주문이 흩어진다(기존 영창 방해 규칙 그대로).
5. **대상은 발동 칸 기준이다.** "대상 변경"은 문장 전체에 적용된다.

> **주의:** 화염 바로 다음 칸에 방패를 놓으면 **항상** 이어진다. "3칸 화염으로 카운터, 4칸 방패로 막기"처럼 따로 쓰려면 화염에 발사를 붙이거나(화염구, 마나 +1) 칸을 하나 띄워야 한다. 이 제약이 답답하면 8절의 "이어짐 조건"을 조정한다.

```
  1칸        2칸            3칸          4칸     5칸
 [화염] ──▶ [방패]         [화염]
            +발사           +강하게
  영창      ★불붙은         ★강한
            투척 방패        기본 화염
```

## 4. 주문표

피해는 그로기(×2)와 비그로기(×0.5) 배율을 적용하기 전의 기본값이다. 발사가 없는 공격은 근거리 적에게만 맞는다.

| 칸 구성 | 주문 이름 | 비용 | 차지 칸 | 기본 피해 | 막기 | 특징 |
|---|---|---|---|---|---|---|
| `[화염]` | 기본 화염 | 1 | 1 | 4 | – | 화염 |
| `[화염+발사]` | 화염구 | 2 | 1 | 4 | – | 화염·투사체 |
| `[화염+강하게]` | 강한 기본 화염 | 2 | 1 | 6 | – | 화염·강타 |
| `[화염+발사+강하게]` | 강한 화염구 | 3 | 1 | 6 | – | 화염·투사체·강타 |
| `[방패]` | 방패 | 1 | 1 | – | 2 | 막기 |
| `[방패+강하게]` | 단단한 방패 | 2 | 1 | – | 3 | 막기·강타 |
| `[방패+발사]` | 투척 방패 | 2 | 1 | 2 | 2 (요격) | 투사체·요격 |
| `[방패+발사+강하게]` | 단단한 투척 방패 | 3 | 1 | 2 | 3 (요격) | 투사체·요격·강타 |
| `[화염][방패]` | 불붙은 방패 | 2 | 2 | – | 2 | 화염·막기 |
| `[화염][방패+발사]` | 불붙은 투척 방패 | 3 | 2 | 8 | 2 (요격) | 화염·투사체·요격 |
| `[화염+강하게][방패+발사]` | 거세게 불붙은 투척 방패 | 4 | 2 | 10 | 2 (요격) | +강타 |
| `[화염][방패+발사+강하게]` | 불붙은 단단한 투척 방패 | 4 | 2 | 8 | 3 (요격) | +강타 |

**강하게는 붙은 단어의 역할을 키운다.**
- 화염에 붙으면 화염 피해 +2. 불붙은 투척 방패에서는 불 피해가 오른다.
- 방패에 붙으면 막기 +1. 투척 방패의 충돌 피해 2는 그대로다.
- 어디에 붙든 주문에 **강타** 특징이 붙는다.
- 제자리 불붙은 방패에서는 화염이 피해를 주지 않으므로, 화염의 강하게는 강타 특징만 준다.

### 기존 대비 바뀐 수치

| 주문 | 기존 | 새 규칙 |
|---|---|---|
| 강화 투척 방패 `[방패+발사+강하게]` | 피해 4, 막기 3 | 피해 2, 막기 3 |
| 강화 불붙은 투척 방패 | 피해 10, 막기 3 (한 가지뿐) | 화염 강화: 피해 10, 막기 2 / 방패 강화: 피해 8, 막기 3 |
| 서브가 붙은 주문의 차지 칸 | 단어 수만큼 | 1칸 (서브는 시간을 쓰지 않음) |

## 5. 예시: 강하게·화염·방패 세 장

| 배치 | 결과 |
|---|---|
| `[화염+강하게] [방패]` | 이어짐 → 거세게 불붙은 방패 (막기 2, 강타) |
| `[화염] [방패+강하게]` | 이어짐 → 불붙은 단단한 방패 (막기 3, 강타) |
| `[화염+강하게] [빈칸] [방패]` | 끊김 → 강한 기본 화염 + 방패, 따로 발동 |
| `[방패] [화염+강하게]` | 짝이 아님 → 방패 + 강한 기본 화염, 따로 발동 |

## 6. 조작

| 동작 | 결과 |
|---|---|
| 칸 클릭 | 그 칸을 선택한다 |
| 메인 카드 클릭 | 선택한 칸이 비어 있으면 그 칸에 놓인다. 대상은 지금 선택된 적이다 |
| 서브 카드 클릭 | 선택한 칸의 메인 위에 쌓인다 |
| 놓인 카드 다시 클릭 | 손패로 돌아온다. 메인을 돌려받으면 그 칸의 서브도 함께 돌아온다 |
| 칸 이동 | 선택한 칸의 카드 묶음을 빈 칸으로 옮긴다. 문장은 자동으로 다시 이어진다 |
| 칸 비우기(제거) | 선택한 칸의 카드를 모두 손패로 돌린다 |
| 대상 변경 | 선택한 칸이 속한 문장의 대상을 바꾼다 |
| 계획 확정 | 총비용(놓인 카드 수)을 한 번 지불하고 실행 단계로 간다 |

초안 패널, "배치" 버튼, "초안 비우기" 버튼은 없앤다.

### 화면 표기

- 칸 플랜 줄 1: 그 칸의 카드. 예: `[화염+강하게]`
- 칸 플랜 줄 2: 역할. `★ 주문 이름 → 적 N` / `영창 → 2칸 불붙은 투척 방패` / `(흩어짐)`
- 손패 카드: 놓인 카드는 `[2칸]`, 아니면 `메인` 또는 `서브`
- 미리보기: 선택한 칸이 속한 문장의 주문 이름, 비용, 차지 칸, 특징, 위력

## 7. 탐험(퍼즐) 방

퍼즐 방에는 타임라인이 없으므로, 입력한 순서를 칸으로 읽는다.

- 메인 단어가 나오면 새 칸이 시작된다.
- 서브 단어는 **바로 앞 메인**에 붙는다. 메인보다 서브가 먼저 오면 시전할 수 없다.
- 한 번에 하나의 문장만 시전할 수 있다. 이어지지 않는 메인이 둘 이상이면 시전할 수 없다.

| 입력 | 결과 |
|---|---|
| 화염, 발사 | 화염구 |
| 방패, 발사 | 투척 방패 (충격판 작동) |
| 화염, 방패, 발사 | 불붙은 투척 방패 |
| 화염, 발사, 방패 | 시전 불가 (발사된 화염은 방패와 이어지지 않음) |
| 발사, 화염 | 시전 불가 (서브가 메인보다 먼저) |

## 8. 결정 사항과 튜닝 포인트

이번 구현에서 고른 기본값이다. 플레이테스트 뒤 바꿀 수 있다.

| 항목 | 기본값 | 다른 선택지 |
|---|---|---|
| 이어질 때 앞 칸 | 영창으로 흡수 (따로 공격하지 않음) | 앞 칸도 따로 발동 |
| 이어지는 짝 | 화염(발사 없음) → 방패 하나 | 방패→화염, 화염→화염 추가 |
| 이어짐 조건 | 이웃하면 자동으로 이어짐 | 칸 사이 연결 토글을 플레이어가 켜야 이어짐 |
| 강하게 수치 | 화염 피해 +2 / 방패 막기 +1 | 방패에도 충돌 피해 +2 |
| 서브의 시간 비용 | 없음 (마나만) | 서브 1장당 영창 1칸 |
| 같은 서브 중복 | 금지 | 강하게 2장 = +4 |

## 9. 범위 밖

- 그레이박스 프로토타입(`Assets/Scripts/Asmegica`, `AsmegicaGraybox.unity`)은 기존 그룹 규칙을 그대로 쓴다.
- 씬 UI 배치는 바꾸지 않는다. 쓰지 않게 된 "배치"·"초안 비우기" 버튼은 코드에서 숨긴다.

## 10. 테스트 체크리스트

에디터 메뉴 (브랜치 작성 시점에 모두 통과):
- [x] `TxRpg/마법 칸 쌓기 규칙 검증` 통과
- [x] `TxRpg/전투 개선 규칙 검증 (7절 A·B·C + 예지 일치)` 통과. 7절 A·C는 새 배치(`[화염][방패+발사]`)로 같은 결과를 재현하고, 턴 이월·방패병 시나리오는 화염을 화염구로 바꿔 방패와 끊었다
- [x] `TxRpg/전투 인카운터 솔버 실행` 판정 "통과". 돌격 기사 최적 계획: 2칸 화염, 3칸 화염(격파), 4칸 화염(영창) → 5칸 투척 방패 = 불붙은 투척 방패가 그로기 ×2로 적 HP 20 처치, 내 피해 0

`BattleTest` 씬 플레이:
- [ ] 2칸에 화염, 3칸에 방패를 놓으면 2칸에 "영창", 3칸에 "★ 불붙은 방패"가 뜬다
- [ ] 3칸 방패에 발사를 쌓으면 "불붙은 투척 방패"로 바뀌고 대상이 표시된다
- [ ] 2칸 화염에 발사를 쌓으면 문장이 끊겨 2칸 화염구, 3칸 투척 방패가 따로 뜬다
- [ ] 강하게를 화염 칸에 쌓을 때와 방패 칸에 쌓을 때 미리보기 수치가 다르다
- [ ] 놓인 카드를 다시 누르면 손패로 돌아오고, 메인을 누르면 서브도 같이 돌아온다
- [ ] 칸 이동으로 방패를 4칸으로 옮기면 문장이 끊긴다
- [ ] 돌격 기사 4칸(근접 3)에 영창이 걸리면 실행 시 주문이 흩어진다
- [ ] 같은 칸에 메인 두 장, 같은 서브 두 장을 넣으려 하면 이유와 함께 거절된다
- [ ] 마나를 넘는 계획은 확정 시 거절된다

퍼즐 방:
- [ ] 방패, 발사로 충격판이 작동한다
- [ ] 7절 표의 시전 불가 입력은 사유가 표시된다
